## 三、缺陷清单（含复现步骤）

### BUG-01【高】保存源设置会把“API 地址”清空，导致漫画源整体失效

**影响**：在源设置页只改“图片质量”并保存，也会把必填的 API 域名写成空串；此后该源所有搜索/详情/阅读请求都会失败（DNS 解析 `api` 主机）。

**复现步骤**
1. 以 `admin` 登录，打开 `/sources/copy_manga?tab=settings`。
2. 观察“API地址”输入框为**空**（默认值 `api.copy2000.online` 未回填）。
3. 将“图片质量”从“低 (800)”改为“中 (1200)”，点击“保存”。
4. 打开“检查可读性”标签，点击“检查”；或在 `/search` 用拷贝漫画搜索“海贼”。

**实际结果**
- 检查结果：`失败 · 阶段: catalog`，`SOURCE_ERROR(502): https://api/v3/h5/homeIndex: Dns Failed: resolve dns name 'api:443'`。
- 接口回读：`GET /api/sources/copy_manga/settings` → `values: {"base_url":"","image_quality":"1200"}`。

**期望结果**：空输入应保留/回填默认域名，或保存时阻止空值并提示；保存无关选项不应破坏源。
**恢复验证**：把 API 地址填回 `api.copy2000.online` 保存后，`GET /api/search?source=copy_manga&q=海贼` 恢复 200、返回 30 条。

**复现步骤**
1. 打开 `/comic/copy_manga/cheyezhigeleyuanpian`，点击“收藏”。
2. 面板中“收藏”显示“已添加”。
3. 点击“收藏”一次（发出删除），等待 6 秒。

- 标签在 500 ms、2 s、4 s、6 s 均仍显示“已添加”。
- 关闭再打开面板后显示“收藏 1”（正确）；刷新页面后服务端 `favoriteFolders` 为空。
**期望结果**：删除成功后立即刷新为未添加/数量状态。

### BUG-04【中】排行榜功能不可用（多个源报源脚本错误）

**复现步骤 A（拷贝漫画）**
1. 打开 `/categories/copy_manga/ranking`。
2. 观察页面只有标题和“页 1 / 1”，无任何排行选项/条目。
3. 返回 `/categories`，点击“拷贝漫画”分区里的“排行”标签。

**实际结果**
- `/categories/copy_manga/ranking` 空白：源能力中 `rankingOptions: null`，页面无选项、无请求。
- 排行标签页接口返回 `502 SOURCE_ERROR: Invalid status code: 210`，页面显示“错误 / Invalid status code: 210 / 重试”；重试后无数据。
**复现步骤 B（再漫画）**
1. `/categories` → “再漫画” → 点击“日排行”。
**实际结果**：`错误 / at load (eval_script:215:30)`。
**期望结果**：排行榜应展示列表；源不支持时应提示“该源不支持排行榜”，而非暴露脚本堆栈/状态码。
